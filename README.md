# hackathon



https://uust.ru/student-unions/



Кейс: «Умный помощник для кампуса» Задача: создать прототип информационного сервиса, который помогает студентам ориентироваться в жизни университета. Описание: Студентам 1 курса часто сложно быстро разобраться, где находится аудитория, когда начинается пара, какие кружки или мероприятия проходят в кампусе. Нужно придумать сервис (веб-приложение, чат-бот (max) или консольная программа), который будет решать часть этих задач. Возможные функции (на выбор команд): − Поиск аудитории по номеру (выдает корпус и краткое описание маршрута). − Расписание занятий (подгрузка готового CSV/JSON или имитация базы данных). − Напоминания о предстоящих мероприятиях. − Мини-чат или «FAQ» для часто задаваемых вопросов. − Рекомендации кружков и клубов по интересам. Ограничения: − Всё должно работать с простыми технологиями, доступными новичкам: Python, HTML+CSS+JS, Telegram Bot API и т. д. − Дизайн может быть минимальным, но должна быть понятна логика работы. Критерии оценки: − Польза для студентов (решает ли сервис реальную проблему). − Удобство интерфейса. − Оригинальность (новые идеи, необычная подача). − Техническая реализация (работоспособность, качество кода). Дополнительно для мотивации: Можно добавить игровые элементы — например, «поиск аудитории превращается в миниквест», или сервис начисляет виртуальные «баллы активности».   brainstorm me
