# Campus Helper

Campus Helper — прототип информационного сервиса для студентов УУНиТ, разработанный в рамках хакатона.

Цель проекта — помочь первокурсникам быстрее освоиться в университете, предоставив в одном месте полезную информацию о кампусе, студенческой жизни и возможностях для внеучебной деятельности.

## Возможности

- Главная страница с навигацией по сервису.
- Раздел **«Найди себя»** — тесты для подбора спортивных секций, кружков и студенческих объединений по интересам.
- Раздел **«Карты кампуса»**:
  - схемы учебных корпусов;
  - схема бесплатного Wi-Fi;
  -  Раздел **«Карты кампуса»**
  - возможность открыть изображения в полном размере.
- Система регистрации и авторизации пользователей.

## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone https://github.com/AyNur207/hackathon.git
cd hackathon
```

2. Создать виртуальное окружение (необязательно, но рекомендуется):

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Запустить приложение:

```bash
python main.py
```

После запуска сайт будет доступен по адресу:

```
http://127.0.0.1:8080
```

## Ограничения

Во время разработки планировалось реализовать раздел объявлений с использованием Supabase и Streamlit.

К сожалению, не удалось интегрировать Streamlit-приложение в Flask таким образом, чтобы раздел открывался напрямую через главное меню сайта. По этой причине финальная версия проекта включает только основную функциональность, а раздел объявлений запускается отдельно как самостоятельное Streamlit-приложение. Однако мы работаем над устронением этой проблемы
